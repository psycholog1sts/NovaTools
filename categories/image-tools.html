Image workflow guide

This category is organized around common user intent, not just a list of links. Start with the task below, then open the tool that best matches the output you need.

Five common tasks

  • Make files lighter: compress images before web upload or email.
  • Change format: convert to WebP/AVIF for web delivery or PNG/JPG for compatibility.
  • Resize first: set dimensions before compression to avoid quality surprises.
  • Prepare branded assets: watermark when attribution or reuse control matters.
  • Check metadata: remove metadata before sharing sensitive images publicly.

Which tool should you choose?

Choose compress for smaller files, convert for compatibility, resize/crop for layout, watermark for branding, and metadata tools for safer sharing.
