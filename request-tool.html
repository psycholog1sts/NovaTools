Request a Tool

Have an idea for a new utility, calculator, converter, or workflow helper? Use this page to prepare a tool request email draft. This is not a backend submission form.

How to make a useful request

The best requests explain the problem clearly, not just the tool name. Tell us what you are trying to do, who the tool is for, and what a successful result should look like.

Helpful request details

  • What task you want to solve
  • Who would use the tool
  • What inputs and outputs you expect
  • Whether the tool belongs to an existing category
  • Any example sites or similar tools

Current category fit

Available categories: PDF Tools, Image Tools, Finance Tools, Developer Tools, Text & Writing, Converters, Calculators, Security Tools, Social Media, Productivity, Data Tools, Design Tools.

What happens after you submit

Your email client opens with a prepared draft. You can edit it before sending. This keeps the process transparent and avoids pretending there is a live backend submission system when there is not.
