What this Todo List does

This is a lightweight personal task manager for quick browser-based planning. You can create tasks, change their priority and due date later, mark them complete, filter the workspace, and create a portable JSON backup.

It deliberately does not provide cloud sync, reminders, team assignment or account-based sharing. Use a dedicated collaborative task service when those features are required.

How to use it

  1. Enter a task, priority and optional due date, then choose Add task.
  2. Use Edit on an existing item to update it without deleting completion history.
  3. Check tasks when finished and use the filters to focus the list.
  4. Choose Export JSON backup before clearing browser data or moving the list manually.
  5. Choose Restore JSON backup to replace the current list with a validated backup file.

Privacy and safety

Persisted and imported records are normalized before rendering. Task text is written with DOM text APIs rather than HTML interpolation, so task content such as markup remains literal text. Backup restoration accepts JSON and validates text length, priority, dates, completion state and identifiers before data enters the workspace.

Limits

  • The list is local to this browser profile and does not sync automatically.
  • Due dates are visual only; the page does not schedule notifications.
  • Restore replaces the current list after confirmation when tasks already exist.
  • Each task is limited to 500 characters and a restored backup is capped at 5,000 tasks to bound browser work and storage pressure.

Frequently asked questions

Where are my tasks stored?

They are stored in this browser's localStorage under the NovaTools Todo List origin. Task content is not uploaded for the Todo List workflow.

Can I edit a task?

Yes. Choose Edit beside the task, change its text, priority or due date, and save the changes. Its completion state and original creation timestamp are preserved.

Can I back up my tasks?

Yes. Export creates a local JSON file containing the normalized task records. Restore reads a JSON backup on your device, validates its records and replaces the current list after confirmation.

Will the list appear on another device automatically?

No. There is no account or cloud synchronization. Move it manually by exporting a JSON backup and restoring that file in the other browser.

What happens when a task is overdue?

An incomplete task with a past due date receives an overdue date label. The page does not send a reminder or notification.
