How NovaTools works

  • Nothing uploaded for local tools Converters and calculators run in your browser. Tools that need a network source say so on the page.
  • Limits written down Every published tool lists what it assumes, the range it accepts and what it will not do.
  • Refuses rather than guesses Out-of-range or undefined input returns the reason, not a plausible-looking number.
  • No account, no paywall Every tool listed here is usable without signing in. Nothing is gated.
