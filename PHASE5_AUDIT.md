# PHASE 5 SEO Structured Data Audit

Scope completed: src/components/Analytics.mjs now generates page-type-specific JSON-LD and injects it through the shared applySeoHead path before the closing head tag. Existing application/ld+json blocks in generated HTML are removed during head application so each page receives the current Phase 5 schema output from one shared generator.

Schema types implemented:
- WebSite for home pages.
- SoftwareApplication for tool pages.
- ItemList with ListItem children for category pages.
- Article for blog article pages.
- AboutPage plus Organization as separate JSON-LD script tags for about pages.
- ContactPage for contact pages.
- WebPage for legal and fallback static pages.

Meta tags verified and completed through shared head generation:
- title is normalized from the page h1 when available so the built title tag and h1 text align.
- meta name="description" is preserved per page, escaped, and capped below 200 characters for social reuse.
- link rel="canonical" uses the absolute canonical URL on https://mc-novatools.com.
- og:title matches the h1-derived page title.
- og:description matches the escaped page description and remains under 200 characters.
- og:url uses the absolute canonical URL.
- og:type is article for blog routes and website for other page types.
- og:image uses the absolute 1200x630 site image https://mc-novatools.com/og-image.svg.
- og:image:width is 1200.
- og:image:height is 630.
- og:site_name is MC NovaTools.
- og:locale defaults to en_US, with tr_TR support for Turkish path/query routes.
- twitter:card is summary_large_image.
- twitter:title matches og:title.
- twitter:description matches og:description.
- twitter:image matches og:image.

Sitemap and robots verification:
- public/sitemap.xml and root sitemap.xml are generated with urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9".
- lastmod values now use W3C datetime format without milliseconds and with +00:00 timezone.
- Home URLs use daily changefreq and 1.0 priority.
- Individual tool URLs use weekly changefreq and 0.8 priority.
- Blog hub and article URLs use weekly changefreq and 0.6 priority.
- Category URLs use monthly changefreq and 0.6 priority.
- Legal/static policy URLs use monthly changefreq and 0.4 priority.
- public/robots.txt references https://mc-novatools.com/sitemap.xml.
- Generated sitemap URL count is 4159, under the 50000 URL protocol limit.
