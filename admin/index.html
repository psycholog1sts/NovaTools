🔒 Security notice

Admin access is not available in the static site.

NovaTools MC is deployed as a static, browser-first application. A client-side admin login cannot provide secure authentication, authorization, audit logging, or secret handling.

For production operations, administrative features must run behind a server-side control plane with authenticated sessions, role checks, rate limiting, and protected environment variables.

  • No hardcoded admin credentials are shipped to the browser.
  • No API keys, tokens, or secrets should be entered into this static page.
  • No visitor, revenue, or operational metrics are displayed unless backed by a verified backend source.
